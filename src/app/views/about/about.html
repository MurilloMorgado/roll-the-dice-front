Rolagem de Dados de RPG com Integração Front-End e Back-End

Este projeto foi desenvolvido com o objetivo de praticar a integração entre front-end, back-end e banco de dados. Ele simula a rolagem de dados de RPG e registra os resultados em um histórico acessível ao usuário.

O funcionamento é simples: o usuário seleciona um tipo de dado (como D6, D20, etc.) e clica em um botão para rolá-lo. Essa ação envia uma requisição ao back-end com a informação do dado escolhido. O servidor então gera um número aleatório correspondente ao tipo de dado, salva o resultado em um banco de dados H2 e o envia de volta ao front-end para exibição.

O banco H2 está configurado para criar automaticamente as tabelas necessárias ao iniciar a aplicação. Cada jogada é registrada e exibida no histórico, permitindo ao usuário acompanhar os resultados anteriores.

Entre os principais conceitos abordados neste projeto, destacam-se:

  • Comunicação entre front-end e back-end por meio de requisições HTTP;
  • Geração de números aleatórios no back-end com base nos parâmetros recebidos;
  • Persistência de dados utilizando um banco de dados relacional (H2);
  • Exibição dinâmica dos resultados e do histórico de jogadas no front-end.

Este projeto oferece uma base sólida para entender a comunicação entre as diferentes camadas de uma aplicação web moderna.
